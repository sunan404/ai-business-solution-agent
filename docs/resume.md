# 简历项目描述

项目：AI 商业需求诊断助手｜个人作品集项目

1. 基于 Python 与 Streamlit 开发客户需求诊断原型，支持访谈文本与 TXT、Markdown、CSV、Excel 资料输入，输出业务信息、痛点、优先级、建议及待确认问题。
2. 实现本地关键词规则、影响与紧迫度评分、原文证据摘录及 Markdown 报告导出，构建游戏发行与消费品牌两个明确标注为虚构的演示案例。
3. 集成可选 OpenAI / DeepSeek LLM 模式，通过环境变量读取密钥，实施 JSON 与证据校验、输出限制、共享及客户配额和结构化日志；完成两个虚构案例的真实 DeepSeek 联调，补充 Docker 分发、CI 与 25 条标注样例的规则回归评估。

以上描述不代表真实客户使用、业务增长、性能收益或语义质量认证。小样本 API 联调不等于“已验证业务效果”；当前没有向量检索或多智能体编排，不写“RAG 系统”或“多 Agent 平台”。
