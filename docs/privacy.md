# 隐私说明

生效版本：0.2.0，2026-09-30。适用于本应用的本机运行与受控试点。公开服务的运营方与联系方式由部署者在页面配置；未配置时不得作为正式企业服务提供。

## 我们处理什么

为了生成客户需求诊断报告，应用处理你主动提供的文本、文件内容和资料名称。应用不要求姓名、电话、邮箱或客户身份信息。请使用虚构资料或已获授权且完成脱敏的资料，不要上传公司机密、敏感个人信息或密钥。

## 数据去了哪里

本地规则模式在运行应用的服务器中分析，不发送给模型服务。如果你在自己电脑运行，服务器就是这台电脑；如果访问远程服务，上传内容会进入该服务器内存。

只有选择 LLM 增强模式并勾选发送确认后，资料名称与提取文本才会发送至部署配置的 OpenAI 或 DeepSeek。页面标明当前服务商。服务商可能在其他地区处理数据，并按其合同与数据政策处理请求；OpenAI 请求的 `store=False` 不等于服务商绝不保留任何数据，也不能套用于 DeepSeek。涉及个人信息或企业受限数据时，请先与运营方确认适用合同、传输要求与合法依据。

## 保存与删除

应用不主动把上传文件或报告保存到磁盘数据库。资料与报告保留在运行进程及当前页面会话中；刷新、断开或关闭页面不保证立即清除服务器内存，进程退出后才释放相关内存。下载的报告保存到你的设备，由你管理。

预算数据库仅包含按日期汇总的请求预留次数、token 预留量与估算金额；每次写入时清理超过 30 天的汇总。应用日志包含随机诊断编号、错误类别、时长及 token 用量，不记录原文、文件名或密钥。日志、访问日志、备份与模型服务保留期由部署运营方另行配置和告知。

## 你的选择

你可以始终使用无需 API Key 的规则模式，拒绝 LLM 外发、停止使用，或联系页面所示运营方咨询数据处理、访问与删除请求。应用无法代替运营方处理模型服务和部署平台中的删除申请。

本说明描述当前技术行为，不构成合规认证。正式处理真实企业或个人数据前，应由运营方补全身份、联系方式、保存期限、受托服务商与适用法律要求。
