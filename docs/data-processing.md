# 数据处理说明与企业试点约定草案

这份说明用于客户评审；正式委托处理协议须由双方补全并确认，当前不是已签署合同或合规认证。

| 项目 | 当前软件行为 / 需确认事项 |
| --- | --- |
| 处理目的 | 根据授权资料生成业务诊断草稿，不用于本应用训练模型 |
| 处理范围 | 输入文本、文件提取内容、资料名称；不需要身份或联系方式 |
| 处理方式 | 服务器内存中规则分析，或经用户确认发送至配置的 OpenAI / DeepSeek |
| 资料存储 | 本应用不主动落盘上传文件或报告；下载副本由使用方保管 |
| 运行记录 | 无正文的错误/用量日志；30 天以内的每日汇总预算，不含用户身份 |
| 访问控制 | 受控试点共享口令；不具备企业单点登录、分角色权限或租户隔离 |
| 受托链条 | 部署平台、模型服务及其数据政策需要运营方列明并经客户审查 |
| 传输位置 | 本地规则不发给模型；远程上传和所选模型服务商处理位置须按部署与合同确认 |
| 数据期限 | 内存会话、部署日志/备份和服务商期限须由双方约定，不能承诺即时全链路删除 |
| 安全措施 | 上传/解压限额、口令、预算、无正文日志；上线需 HTTPS 与代理限速 |
| 数据请求 | 运营方接收咨询、访问和删除请求；客户确认联系人和响应期限 |
| 事件处置 | 运营方确认通知对象、时限、取证方式与密钥轮换流程 |
| 终止处理 | 停止访问、清理运营方可控数据，并确认服务商和备份清理条件 |

上线前应填写双方名称与联系方式、实际资料分类、合法处理依据、期限、子处理商、支持数据请求流程以及安全责任。若含个人信息或跨境处理，需针对实际部署开展法律和安全审查，不能凭本模板认定满足所有要求。

参考：[《中华人民共和国个人信息保护法》官方全文](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)。本模板不代替专业法律意见。
