# 使用条款

版本：0.3.1，2026-10-01。适用于受控试点和演示。

本工具帮助售前、商业分析和客户成功人员整理业务资料，输出供人工讨论的诊断草稿。它不承诺结论正确、实施一定可行或产生特定商业收益；重要决策必须由你核对原文并与客户确认。

你应拥有输入资料的使用权限，先完成脱敏；不得上传机密、密钥或无权处理的个人信息，不得绕过访问控制、配额或干扰服务。选择 LLM 模式会向页面标明的 OpenAI 或 DeepSeek 发送本次资料，可能消耗运营方账户额度；无需 LLM 时可使用本地模式。

报告中的业务判断、优先级和建议可能误判。证据摘录存在于原文不代表它足以支持结论。你应自行核验报告、管理下载副本，不能将未确认的信息作为客户事实或已交付成果传播。
