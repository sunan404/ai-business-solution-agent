# 2 分钟演示录制脚本

状态：脚本已准备，视频尚未录制。全程使用内置虚构案例与本地规则模式，无需 API Key。

录制准备：启动应用，将浏览器调整为 1440×900 或 1920×1080，关闭桌面通知和无关标签页。不要打开终端环境变量、密钥文件或真实客户资料。先试跑一次生成与下载，清理下载文件名中的个人信息。

| 时间 | 画面与操作 | 旁白 |
| --- | --- | --- |
| 00:00–00:15 | 首页，显示项目名称和本地规则模式 | 这是 AI 商业需求诊断助手，面向售前、商业分析和客户成功人员。它把访谈纪要和业务表格整理为客户讨论报告。 |
| 00:15–00:35 | 选择游戏发行团队，展开虚构访谈，指向角色、工具和问题描述 | 这里使用完全虚构的海外发行案例。资料包含市场验证目标、跨部门素材交付、渠道跟进和数据汇总问题。也可以粘贴文本或上传文件。 |
| 00:35–00:55 | 点击生成，展示目标、角色、工具及其证据 | 系统从输入中识别业务信息。每项识别结果附带原文摘录，方便回到客户资料核验。当前是本地规则模式，不需要密钥。 |
| 00:55–01:15 | 滚动到痛点，展示影响、紧迫度、证据和建议 | 痛点按影响与紧迫度的规则分数排序，并关联知识库、协作流程和数据管理建议。分数属于启发式判断，不能直接等同于客户确认的优先级。 |
| 01:15–01:35 | 切换消费品牌案例，再次生成 | 第二个案例来自 Excel，演示经销商资料和活动复盘问题。两种输入共用报告结构，便于售前沟通和方案讨论。 |
| 01:35–01:50 | 展示待确认问题，点击下载 Markdown | 报告保留待确认问题，可以下载 Markdown 继续编辑。资料缺少明确线索时会提示补充信息，规则仍可能误判，需要人工核验。 |
| 01:50–02:00 | 指向 LLM 模式入口，不发起真实调用 | 项目还提供可选 LLM 模式，支持 JSON 结构及证据校验。这次展示的是本地流程，模型调用需要另行安全配置。 |

录制后将视频发布到自己的 GitHub Release 附件或视频平台，并把真实视频链接放到 README 顶部。不要使用占位链接冒充已完成演示，不要把未执行的 LLM 流程剪辑成实测结果。
