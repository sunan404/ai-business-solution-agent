- 消费品牌合并标题不再作为 Pandas 表头；按首五条非空行检测实际表头、保留虚构声明，测试确认提取文本无 `Unnamed:`。
- 删除未使用 CSS。工作目录中的 `.agents`、虚拟环境和缓存保留给开发工具，Git 忽略且白名单 ZIP / Docker 上下文不纳入，不删除用户的工具目录。
- LLM 加输出上限、可控超时与 SDK 重试；共享 SQLite 原子预留、会话限额、失败不退款、持久 volume 和生产启动配置门。
- 可选共享口令、外发确认、隐私与条款页面；未配置生产口令/运营方/联系信息时拒绝使用。
- 错误日志仅含编号、类别、耗时和用量；未知异常只记录类型，不记录正文/堆栈。区分密钥、权限、模型不存在、网络、限流、输出和配额。
- 输入限制从页面和解析器两层执行。CSV 支持 UTF-8 与 GB18030，表格超限明确拒绝；XLSX 检查体积、压缩比、宏/外链、XML 实体。
- 两种模式使用相同优先级函数和排序；缺失影响/紧迫时待确认。本地过滤明确否定与纯期望，不声称解决所有作用域问题。
